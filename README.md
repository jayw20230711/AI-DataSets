# AI-DataSets

This repository was created to help anyone who study the book "Machine Learning with Python Tutorial by Bernd Klein", and to 
follow along the principals and examples easily. I ustilized the book to learn coding as well as to learn more about the datasets 
featured in the examples. That way if you follow the codes given here it will be very easy to understand the principles given in the book and the datasets itself. Certain cases I included codes that I added to extend the explanation, just to show how I understood the book. Also, I saved the codes along with the output so that anyone just follow along the code can easily understand the 
logic behind the coding
